# Manuscript correspondence

The associated manuscript is *Smoothly Tilted MCMC Importance Sampling for
Small Tail Probabilities* by Noam Chowers, Shuli Halperin, and Saharon Rosset.

The article's theoretical rate table and mathematical statements are analytic
results and require no data analysis. Every computational exhibit is generated
by `workflow/reproduce.py`; the exact output names are listed in the top-level
README. The main results table is supplied as both CSV and LaTeX. The scenario
bank and pilot/production allocation tables are supplied as CSV.

This directory is a correspondence note rather than a duplicate of the article
source. JASA receives the manuscript separately from these reproducibility
materials.
